## 2. Root Cause Analysis: Frontend `npm ci` Failure & Cross-Platform Resolution

### Initial Failure & First-Pass Diagnosis
In initial clean clones and in GitHub Actions run `39122776186`, `npm ci` failed with:
```text
npm error code EUSAGE
npm error Invalid: lock file's @emnapi/wasi-threads@1.2.1 does not satisfy @emnapi/wasi-threads@1.2.3
npm error Missing: @emnapi/core@1.10.0 from lock file
```

### Remote CI Environment Failure (Run 39125829378)
In GitHub Actions run `39125829378` (Ubuntu `ubuntu-latest`, Node `22.23.3`, npm `10.9.9`), `npm ci` failed with:
```text
npm error code EUSAGE
npm error Missing: @emnapi/runtime@1.11.3 from lock file
npm error Missing: @emnapi/core@1.11.3 from lock file
```

### Dependency Chain & Exact Root Cause
Tracing the full dependency requirements across the graph:
1. `node_modules/@tailwindcss/oxide` requires optional dependency `@tailwindcss/oxide-wasm32-wasi`.
2. `node_modules/@tailwindcss/oxide-wasm32-wasi` declares dependencies:
   - `@emnapi/core: ^1.11.1`
   - `@emnapi/runtime: ^1.11.1`
   - `@emnapi/wasi-threads: ^1.2.2`
   - `@napi-rs/wasm-runtime: ^1.1.4`
3. `node_modules/@img/sharp-wasm32` declares dependencies:
   - `@emnapi/runtime: ^1.11.3`
4. In npm 10 (`10.9.9`), the Arborist lockfile validator strictly verifies that all declared dependencies of optional packages in `packages` are resolvable from hoisted or nested nodes in the lockfile.
5. In the earlier Windows-generated repair with npm 11, npm placed `@emnapi/core: 1.10.0` nested inside `@unrs/resolver-binding-wasm32-wasi` and did not populate hoisted entries for `@emnapi/core@1.11.3` and `@emnapi/runtime@1.11.3`.
6. When evaluated under npm 10.9.9 (both in GitHub Actions Ubuntu and reproduced locally via `npx npm@10.9.9 ci`), npm 10 halted with `Missing: @emnapi/runtime@1.11.3 from lock file` and `Missing: @emnapi/core@1.11.3 from lock file`.

### The Cross-Platform Minimal Repair
- **No changes to `frontend/package.json`**: Zero direct dependencies added or modified.
- **Regenerated lockfile using the CI npm version (`npm@10.9.9`)**:
  Executed `npx npm@10.9.9 install --package-lock-only` in `frontend/`.
- **Result**:
  - Populated hoisted `node_modules/@emnapi/core` (`1.11.3`) and `node_modules/@emnapi/runtime` (`1.11.3`).
  - Populated nested `node_modules/@tailwindcss/oxide-wasm32-wasi/node_modules/@emnapi/core` (`1.11.1`) and `@emnapi/runtime` (`1.11.1`).
  - Removed stale/redundant `"peer": true` attributes generated by npm 11.
- **Dual Verification**:
  - `npx npm@10.9.9 ci` (CI version): **PASS (exit code 0 in 42s)**
  - `npm ci` (npm 11.6.2): **PASS (exit code 0 in 43s)**
  - Verified lockfile is **unmodified** after `npm ci`.
