# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-05

### Added
- Developer SDK with `waswitRun()` and `waswitPreload()` public APIs.
- Deterministic frozen-policy runtime selection using the empirical phase 5 model.
- Browser-oriented WebAssembly package optimized for Vite/Next.js/ESM consumers.
- TypeScript declarations directly available in the SDK.
- Developer Playground for interactive testing.
- External package validation artifacts for deployment smoke tests.
- Developer integration documentation in `docs/developer-integration.md` and `examples/`.

### Security
- Verified package does not leak research artifacts or data.
